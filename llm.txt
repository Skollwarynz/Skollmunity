# Skollmunity

> Skollmunity is an independent, non-commercial research blog by Skollwarynz about visual perception, color psychology, fine art, costume design, cinema, anime, and narrative visual theory.

This compatibility file points to the same curated resources as the standard `/llms.txt` file.
